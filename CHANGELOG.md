# Changelog

All notable changes to AgentForge will be documented here.

### Added
- Multi-agent system (Planner, Research, Reasoning, Critic)
- Workflow orchestration with phase-based execution
- Memory layer (JSON-based storage)
- Tool system (Search, Document, Analytics)
- Mock LLM provider (no API key required)
- OpenAI provider structure (placeholder)
- TypeScript implementation with strict mode
- Example workflow (Growth Strategy)
- Comprehensive documentation
- GitHub templates (issues, PR, CI)

### Features
- 🧠 **PlannerAgent** - Task decomposition and planning
- 🔍 **ResearchAgent** - Information gathering with tools
- 💡 **ReasoningAgent** - Insight synthesis
- 🔬 **CriticAgent** - Quality review and critique
- 🛠️ **Extensible tool system** - Easy to add custom tools
- 💾 **Memory persistence** - Context across workflows
- 🔄 **Workflow state management** - Observable execution
- 📊 **Execution logging** - Detailed phase tracking

### Technical
- TypeScript 5.3+ with strict mode enabled
- Node.js >=18.0.0 required
- Clean architecture with separation of concerns
- Interface-based design for extensibility
- Comprehensive type safety

### Documentation
- Complete README with architecture diagrams
- API usage examples
- Contributing guidelines
- MIT License

### Status
- **Experimental**: Reference implementation
- Tests and production provider implementations planned for v2.0.0
